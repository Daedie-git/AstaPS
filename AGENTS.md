# AstaPS Fork Instructions

These preferences apply to the local/customized fork. Keep this file out of upstream PRs.

## Deployment

- Deploy and restart the local AstaPS server after a fix passes validation, unless the user explicitly asks otherwise.
- Back up the installed archive and preserve unrelated deployed patches; avoid replacing it with an older checkout build.
- Account, reward, or puzzle resets require their own explicit request. Deployment alone does not authorize them.
